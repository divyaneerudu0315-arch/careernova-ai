# 🚀 CareerNova AI

### AI-Powered Personalized Career Guidance Platform

**Live Application:** https://careernova-ai-1.onrender.com/

## 📌 About the Project

CareerNova AI is an AI-powered career guidance platform designed to help students explore suitable career paths based on their skills, interests, and educational background.

The platform brings together career recommendations, resume analysis, skill gap identification, personalized learning roadmaps, career readiness insights, and AI-powered career guidance in one interactive application.

CareerNova AI aims to make career planning more accessible and help students identify opportunities for improving their skills and preparing for their professional journey.

## ✨ Key Features

### 1. Career Intelligence
Provides personalized career recommendations based on a student's skills, interests, and educational background.

### 2. Student Profile Management
Allows students to enter and manage their profile information, skills, interests, and education.

### 3. AI Resume Analysis
Analyzes uploaded resumes and extracts relevant information to help students understand their existing skills and experience.

### 4. Skill Gap Analysis
Helps identify missing or underdeveloped skills relevant to a student's target career and highlights areas for improvement.

### 5. Personalized Learning Roadmap
Provides structured learning guidance to help students develop the skills needed for their career goals.

### 6. Career Readiness Assessment
Provides career-readiness insights based on the student's profile, skills, and identified development areas.

### 7. AI Career Coach
Offers AI-powered career guidance and answers career-related questions through an interactive chatbot.

### 8. Interactive Dashboard
Presents career insights, recommendations, and progress information through a user-friendly dashboard.

## 🧠 Core Engines

- **Career Intelligence:** Personalized career recommendations and profile-based insights.
- **Adaptive Skill Growth:** Skill gap identification and personalized learning guidance.
- **Job Readiness & Simulation:** Career-readiness insights to support professional preparation.

## ⚙️ Run the Project Locally

### Prerequisites

- Python installed on your system
- Git installed on your system
- Required API credentials for AI features that use an external API

### 1. Clone the Repository

```bash
git clone https://github.com/divyaneerudu0315-arch/careernova.git
```

### 2. Open the Project Directory

```bash
cd careernova
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a local `.env` file and configure the environment variables required by the application, including the Groq API key if needed.

**Important:** Never commit API keys, passwords, or other secrets to GitHub.

### 5. Run the Application

```bash
streamlit run app.py
```

The application will open locally in your browser, typically at:

`http://localhost:8501`
